# 九宫小六壬 (XiaoLiuRen)
小六壬是中国民间流传极广的一种简易占卜术，属于“六壬神课”的民间简化版。因为它不需要罗盘、铜钱等工具，仅靠在手指上掐算，所以又被称为“掌中诀”，民间也常附会为“诸葛马前课”（相传诸葛亮出征前在马前掐指占算）

本项目基于 Qt 的九宫小六壬占卜工具，支持 `Windows` 和 `Android` 平台。

## 功能
- 手动选择月/日/时起卦
- 随机起卦
- 九宫结果展示与综合断语

## 编译
1. 安装 Qt 6.x（勾选 MinGW 64-bit）
2. 打开 `XiaoLiuRen.pro`
3. 构建 → 运行
